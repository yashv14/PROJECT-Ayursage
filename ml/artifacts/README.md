Request a controlled transfer of the finalized V17 model bundle, inference source,
feature and target metadata, encoders, preprocessing pipeline, categorical values,

pickle/joblib files. Keep binary artifacts and patient data outside version control.

unverified until the actual bundle and requirements have been inspected.
